# sherlock-framework-security

聚合认证主体、JWT 服务和 Spring Security 集成模块。

| 叶子模块 | 职责 |
| --- | --- |
| [`security-api`](security-api/README.md) | 当前认证主体、权限值对象与线程上下文。 |
| [`security-jwt`](security-jwt/README.md) | RS256 JWT 的签发和直接校验。 |
| [`security-spring-boot-starter`](security-spring-boot-starter/README.md) | 资源服务、严格声明校验和上下文绑定。 |
